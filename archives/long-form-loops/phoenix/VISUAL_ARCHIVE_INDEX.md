## Long-form-loop extraction targets
The reusable techniques are:
- hold a single world and hero identity for minutes
- vary materials instead of regenerating the whole image
- use seamless local loops for embers, smoke, reflections, fog and aura
- use transitions only at meaningful state changes
- allow low-amplitude bounded depth while protecting anatomy and architecture
- drive intensity from analysis controls while decoupling the final visual loop from the source song
- prove loops individually before assembly
- retain MP4 + GIF proofs and contact-sheet QC
