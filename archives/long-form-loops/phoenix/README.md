# Mythic Phoenix Visual Production Archive

Branch purpose: preserve the reusable visual-production knowledge from **Tribal House Remastered / Mythic Phoenix** for long-form loop research.

## Source
- Production branch: `song/tribal-house-remastered`
- New archive branch base: current `main`
- Drive root: https://drive.google.com/drive/folders/1zjSYLhWEanmpUS17OmHTJCganZNxaoRE

## Scope
Preserve:
- visual DNA and story/shot structure
- generated still families and visual evolution
- motion proofs
- loops and GIF equivalents
- transitions
- reactive visual clips
- fill clips
- FX-pack indexes and QC evidence
- section proofs / contact sheets / assembly metadata
- render history
- music-scanner reports that informed visual timing and reactivity

Do not preserve as a dependency:
- source WAV/audio payload
- waveform display media as an end product

The scanner-derived reports remain relevant because they explain visual timing. The raw 7,320-frame control report stays in Drive with hash/ID provenance; compact analysis and manifests are copied here.

## Phoenix visual arc
Invocation -> Gathering -> First Manifestation -> Procession / Passage -> Possession / Peak Build -> Threshold Crossing -> Apotheosis -> Release -> Afterglow / Exit.

## Long-form-loop value
This production contains reusable patterns for:
- identity-safe living stills
- bounded 2.5D depth
- material-first motion
- seamless visual looping
- reactive fire/smoke/embers/reflection/light
- music-derived but visually independent timing maps
- loop + GIF dual proofing
- section-level QC before long assembly
- transition families that preserve world continuity
