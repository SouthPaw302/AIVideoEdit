# Ironflame — Canon Rebuild

## Rule
This production is rebuilt from scratch. Do **not** reuse frames, loops, edits, timing, or transitions from prior Ironflame MP4 renders.

Allowed source material:
- `Ironflame (Remastered) (1).mp3`
- supplied lyrics
- approved still artwork where useful
- newly generated production frames
- newly created procedural / audio-reactive layers

## Protagonist
**The IronFlame is a woman.** She is the recurring subject across the mythic-fantasy interpretation. Maintain recognizable face, dark wavy/braided hair, soot/scar texture, dark weathered armor/leather, cloak, and ember-lit visual identity.

## Visual DNA
- dark folk
- mythic fantasy
- haunted but resolute
- iron, flame, rain, stone, wolves, oath, memory
- ember orange -> iron blue -> ash gray -> dawn gold
- cinematic realism blended with painterly / abstract passages

## Motion language
Each production still should become a mini-scene, not a slideshow frame:
- layered parallax / depth motion
- hair and cloak drift
- forge sparks / embers
- smoke / fog / rain
- firelight and shadow movement
- selective character micro-motion
- audio-reactive particles and lighting
- occasional abstract / WMP-inspired visualizer bridges integrated into the fantasy language

## QC rule
Before animation, inspect hands, faces, weapons, armor, props, geometry, text, reflections, and repeated details. Repair or conceal artifacts before motion exaggerates them.
