# Canon Music-Video Workflow

This document defines the production grammar for AIVideoEdit. The song chooses the visual language; the pipeline does not force every song into the same look.

## 1. Listen & Decode
Analyze structure, tempo, dynamics, lyrical images, emotional arc, instrumentation, density, and transitions. Mark section boundaries and high-value sync points.

## 2. Visual DNA
Define:
- core emotion
- world type: realistic / mythic / surreal / abstract / documentary / collage
- camera behavior
- motion density
- palette journey
- symbolism
- realism level
- visualizer role
- ending energy

## 3. Concept & Style Tests
Create small style tests before committing. A song may want cinematic living paintings, 2D animation, stock-like realism, graphic collage, WMP-style visualizers, or a hybrid.

## 4. Asset Creation
Create only assets needed by the shot plan. Preserve recurring subjects, architecture, palette, props, and costume continuity.

## 5. Artifact Scan & Repair
Inspect every still before animation for:
- hands / fingers
- faces / eyes
- instruments / props
- duplicated objects
- perspective / geometry
- nonsense text
- reflections
- continuity
- areas likely to flicker when warped

Repair, crop, mask, darken, replace, or intentionally stylize weak regions.

## 6. Animation & Layering
Prefer living scenes over flat slideshows:
- foreground/midground/background parallax
- depth-based push/pull
- environmental micro-loops
- rain limited to windows/exterior
- fire and practical-light flicker
- smoke / steam / fog / dust / embers
- cloth / hair / curtain drift
- tiny breathing / hand / head / instrument motion
- seamless MP4/WebM loops rather than GIF where possible

## 7. Sync & React
Audio reactivity should feel cinematic, not like an overlay unless the song calls for one.
Possible mappings:
- bass -> fire intensity / depth / fog density
- mids -> particles / texture movement
- highs -> sparks / glints
- transient hits -> light accents / micro-shake / cuts
- vocals -> focus / depth / atmosphere
- sustained reverb -> fog / smoke expansion

## 8. Edit & Transition Design
Transitions must serve the song. Use match cuts, object morphs, smoke dissolves, light leaks, ink, particle fields, hard rhythmic cuts, visualizer passages, or continuous dream transitions.

## 9. Final Grade & Render
Default target:
- 16:9
- 24 fps
- Rec.709
- H.264/HEVC master
- source audio preserved at highest practical quality

Render efficiently: pre-render complex scenes once, reuse seamless loops, then assemble and mux.

## 10. Validation & Archive
Validate:
- exact duration
- audio sync
- no black frames
- no malformed transitions
- no obvious AI artifacts introduced by motion
- consistent color / brightness
- final file opens and seeks correctly

Generate representative contact sheets and QC frames before declaring final.

## Principle
Do not ask, “How do we animate this image?” Ask, “What visual form does this song want?”
