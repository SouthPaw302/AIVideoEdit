# Lessons

A record of decisions and failures that shaped current rules. Read
before assuming a rule is arbitrary or safe to relax.

## Project formation (2026-09-03)

The music-video workflow became a persistent project centered on this
repository so future agents could recover context instead of one chat
being overloaded. Doctrine: one song per branch, reusable tech in
`main`, GitHub as memory/roadmap, large media referenced externally
when appropriate.

## Silver Coin — canonical benchmark

Silver Coin (`song/silver-coin`, V8) became the canonical motion
benchmark: generated/derived stills, layered motion, radiance-field
exploration, living-image behavior, effects, loops, iterative QC. The
real finished V8 file was preserved specifically so future agents
compare against the actual result, not an approximation.

## Irish Eyes / Sigh No More lineage

Irish Eyes evolved out of earlier work including Sigh No More. Source
footage can anchor identity and place, while reusable loops/effects get
promoted into the system. Irish Eyes V1.3 is a completed/QC-passed
canonical production with a point-in-time archive branch.

## Leave It by the Door — don't just replay the source

Giving an agent a user video must not reduce the project to replaying
that video. The system must create its own media, visibly apply prior
effects, and preserve successful source identity where useful.

## FX gate enforcement (2026-09-05)

Repeated cases of effects/transitions being named or wired but not
visibly present led to the FX2 precompile/proof system. **The gate
exists to guarantee visible production behavior — it must never become
a substitute for actually building animated shots.** If a future agent
finds itself satisfied by a passing gate alone, it has misapplied this
lesson.

## IronFlame V3.4 — technically clean, artistically failed

An agent produced a mostly still-image sequence with insufficient
transitions/motion, canonical effects/loops that did not survive
visibly, weakened story from long held storyboard frames, and let
verification/gating substitute for production. **Do not use V3.4 as a
target or polish it further.** The correct continuation was to recover
the existing generated stills, build multiple genuinely moving shots
from them, visibly apply the established effect/loop vocabulary, and
rebuild the story through the edit — not to fix the slideshow in place.

Canon note: the woman is the IronFlame, the recurring mythic
protagonist, in a dark-folk / mythic-fantasy direction. Reference
motion checkpoints without her identity restored are review checkpoints
only, never a replacement canonical master.
