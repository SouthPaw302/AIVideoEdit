# Spatial 3DGS / SuperSplat Production Rule

## Purpose

This document defines when AIVideoEdit may call something a true Gaussian-splat / 3DGS effect and how SuperSplat fits the production pipeline.

Reference project: PlayCanvas SuperSplat
https://github.com/playcanvas/supersplat

## Hard distinction

A 2D Gaussian blur, glow, light field, splatter brush, depth warp, parallax pass, or painterly particle field is **not** 3D Gaussian Splatting.

True 3DGS requires actual scene geometry represented by Gaussian splats, normally reconstructed from a sufficiently overlapping image/video capture or generated by a separate geometry-producing pipeline.

The renderer must not label a 2D approximation as `3DGS` or `SuperSplat` merely because Gaussian kernels are used.

## Canonical role of SuperSplat

SuperSplat is the preferred open-source inspection/editing layer when AIVideoEdit has genuine splat geometry.

Use it for:
- loading and inspecting real Gaussian-splat scenes;
- removing stray splats / floaters;
- cropping the useful scene volume;
- checking camera travel and occlusion behavior;
- preparing spatial shots or camera paths for later compositing;
- validating that a supposed 3DGS asset actually behaves spatially.

Do not use it as a substitute for reconstructing geometry from a single flat hero painting.

## Source requirements

A shot may enter the true-3DGS path only when at least one of these exists:

1. a real `.ply` / supported splat scene produced by a reconstruction pipeline;
2. a multi-view capture with sufficient overlap and parallax to reconstruct one;
3. a validated generated spatial representation that can be exported and inspected as real splat geometry.

A single still image alone stays in the 2.5D / layered-parallax path unless additional views or geometry are produced.

## AIVideoEdit spatial tiers

### Tier 0 — Flat image
Static hero painting with lighting, atmosphere and surface animation only.

### Tier 1 — 2.5D living painting
Depth masks, protected local warps, parallax, water/reflection motion, smoke, rain, fire, light fields, cloth/hair micro-motion.

### Tier 2 — Depth-assisted spatial shot
Explicit depth map / segmented planes / limited camera travel. Still not true 3DGS.

### Tier 3 — True 3DGS
Real splat geometry with viewpoint-dependent parallax and occlusion. SuperSplat can be used to inspect/edit the scene.

## Leave It by the Door — V3 rule

The current accepted V2/V3 hero paintings remain primarily Tier 1 and Tier 2 assets. Do not force them through a fake 3DGS label.

For V3:
- prioritize canonical internal-motion FX first;
- keep camera amplitude restrained;
- use depth-assisted motion only where it improves the image;
- reserve true SuperSplat/3DGS shots for any scene for which valid geometry is later reconstructed;
- if a true splat shot is introduced, compare it against the painterly source and reject it if identity, anatomy or visual continuity degrades.

## Promotion / QC gate for a 3DGS shot

A 3DGS shot is production-approved only after:
- geometry can be inspected in SuperSplat or an equivalent real splat viewer;
- camera movement reveals legitimate parallax/occlusion rather than a 2D warp;
- floaters and reconstruction artifacts are controlled;
- faces/hands/critical instruments remain visually stable;
- a native-cadence rendered proof passes normal black/freeze/temporal QC;
- the shot still matches the song's painterly visual language.

## Naming convention

Use `3DGS`, `Gaussian splat`, or `SuperSplat` only for Tier 3 assets.

Use `Gaussian light field`, `Gaussian mask`, `Gaussian glow`, `2.5D parallax`, or `depth-assisted` for non-3DGS techniques.
