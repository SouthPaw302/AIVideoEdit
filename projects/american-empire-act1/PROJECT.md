# The American Empire — Act I

## Current production
Scene 01: **5:47 AM, Paris** — approximately 80 seconds.

This is a picture-first cinematic comic-book sequence. The user has approved six hero panels as the Scene 01 visual source set. Those panels are canon and must not be regenerated or silently replaced.

Production order for the active phase:

`storyboard -> frame-followable script -> shot packages -> short mode-aware FX proof -> FX lock -> Scene 01 assembly -> picture lock -> score/audio later`

## Visual language
Graphic-novel / comic-book rendering with strong inked value separation, controlled halftone/print texture, pale gray-blue pre-dawn Paris, cream stone, muted cyan contemporary technology and warm amber practical light. Avoid saturated neon and generic cyberpunk spectacle.

## Motion principle
Internal scene motion outranks camera motion. Use existing repo capabilities to create visible depth/parallax, region-specific rain or rain-on-glass, reflections, atmosphere, practical-light response and foreground movement while protecting faces, hands, anatomy and linework.

## Audio
Dialogue, foley and score are intentionally deferred until picture lock by current user direction.
