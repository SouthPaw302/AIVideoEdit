# American Empire Act I — Project Branch Hierarchy

Canonical project namespace:

- `project/american-empire-act1/main` — project integration/root branch; inherits current repository `main` director rules and reusable systems.
- `project/american-empire-act1/scene-01` — Scene 01 production branch.
- `project/american-empire-act1/scene-02` — Scene 02 production branch.
- `project/american-empire-act1/scene-03` — reserved child branch for the next scene.

Legacy branches remain intact for recovery/history:
- `movie/american-empire-act1`
- `song/american-empire-act1-scene1`
- `song/american-empire-act1-scene2`

Rule: future scenes must be created under `project/american-empire-act1/scene-XX` from `project/american-empire-act1/main`, then inherit the immediately prior scene's approved continuity contract where applicable. Reusable improvements belong on repository `main` first, then are synchronized into the project root and active scene branches.
