# Silver Coin — Effects Plan

All effects must be selected from the repository-wide `docs/VISUAL_STYLE_CATALOG.md` and adapted to the Living Pre-Raphaelite Folk Romanticism style. Do not add effects merely because they are available.

| Catalog technique | Silver Coin use | Intensity / rule |
|---|---|---|
| Cinematic living paintings | Foundation for every narrative scene | Required; character and environment must both live |
| 2.5D parallax scene graph | Road, village, tavern, crowd, and close-up depth | Required but subtle; avoid cardboard cutout motion |
| Cinemagraph / micro-loop | Fire, smoke, rain, fabric, crowd, wheel, reflections | Required; seamless MP4/WebM loops when reusable |
| Painterly animation | Preserve brush texture through motion and transitions | Required; reject boiling/crawling pigment |
| Integrated audio-reactive cinematography | Map song energy to light, depth, atmosphere, glints, and cuts | Required; cinematic, not an overlay |
| Object-morph narrative | Silver coin becomes moon/window/eye/light/instrument detail | Primary transition motif |
| Recursive dream transition | Enter or exit through coin reflection where narratively useful | Selective; never repeat mechanically |
| Temporal painting | Cold exterior pigment warms into tavern amber; weather/time shifts | Selective at major structural transitions |
| Continuous dream journey | Maintain flowing geography across road, threshold, and tavern | Preferred edit language |
| Particle systems | Sparks, dust, rain points, smoke motes | Motivated only; no random magical particles |
| 3D Gaussian Splatting / deeper spatial reconstruction | Possible navigable tavern or village establishing shot | Experimental, not required; must retain painterly surface |
| Spectrum/waveform/oscilloscope | Coin engraving, instrument vibration, or reflected light geometry | Optional and nearly subliminal |
| WMP/plasma/tunnel visualizer | No default use | Use only if later music analysis reveals a justified abstract passage |
| Photoreal/documentary/graphic-novel/collage | Not part of the locked primary language | Do not mix without a deliberate later decision |

## Effects QC

Every generated effect must pass:

- painterly-surface consistency
- face/hand/instrument/coin continuity
- stable edges and textures across time
- no unmotivated object creation or disappearance
- no black frames or loop seams
- audio response that supports rather than distracts
- correct perspective, shadow, reflection, and screen direction

Record approved and rejected effect tests in `DECISIONS.md` and update `STATUS.md` before moving to full rendering.
