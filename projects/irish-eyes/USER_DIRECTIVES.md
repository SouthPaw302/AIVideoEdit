# Irish Eyes — User Directives

These directives override presentation habits during production.

1. **Do not create additional storyboards.** The project already has sufficient storyboard/concept material.
2. **Do not preview generated images in chat.** Images are production assets only unless the user explicitly asks to see one.
3. **Do not create concept art for its own sake.** Any newly created image must be intended to become an actual movie shot, texture, plate, matte, transition element, environment extension, or other render input.
4. **Prioritize rendered moving footage.** Work should advance through enhanced real footage, loops, 2.5D shots, PlayCanvas/3D effects, transitions, generated support footage, compositing, scene assembly, and final video renders.
5. Keep work in the current chat/project workflow. Do not move the production to ChatGPT Work unless the user explicitly requests it.
6. Use the user's real video whenever useful, but it is not the only allowed visual source. Create additional photoreal movie material when the lyrics/story require scenes that do not exist in the source.
7. Ask for more real user video only when a specific missing real-world shot would materially improve the finished film.
