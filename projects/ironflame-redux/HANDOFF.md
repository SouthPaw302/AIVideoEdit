# IronFlameRedux Handoff

Branch: `song/ironflame-redux`

Current phase: intake. The project was created from `main` after reviewing the current repository rules and reusable system. User source files have not yet been received in this production.

On receipt of files:
1. inspect every supplied asset and identify audio master, lyrics, references, and identity-bearing material;
2. choose Production Pipeline Branch A or B based on reference availability;
3. analyze the song/lyrics and references before generating or assembling shots;
4. lock visual DNA and storyboard;
5. build real `shot_packages/` and short proof renders before scale-up;
6. resolve FX through `general/reusable/fx_v2/registry.json`, run the fail-closed gate, and verify the lock immediately before real renders;
7. inspect actual exports, not just command success.

Do not inherit story, media, prompts, or production assumptions from older IronFlame branches unless the user explicitly requests it.
