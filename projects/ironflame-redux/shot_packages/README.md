# IronFlameRedux Shot Packages

Use one directory per selected shot. Canonical media subfolders remain `source/`, `alpha/`, `layers/`, `depth/`, `generated/`, `fx_assets/`, `transition/`, `loop/`, `preview/`, and `notes/` as required. Git does not track empty directories, so package documents are created first and media directories appear when actual assets exist.

## First proof wave
These four representative packages define the initial visual grammar before any scale-up:
- `S01B` — forge action/environment proof;
- `S01C` — protagonist identity close-up benchmark;
- `S05B` — iron-blue moon/wolf exterior benchmark;
- `S09B` — ash-gray -> dawn-gold ruined-hall spatial benchmark.

Do not generate the remaining full library until these prove that the Redux look reads as living-image cinema, protects protagonist identity, and survives the actual export/QC path.

Each package document records source-frame brief, layer/depth plan, motion grammar, candidate approved FX IDs, artifact guards and KEEP criteria. Exact time placement remains pending the Redux audio master.
