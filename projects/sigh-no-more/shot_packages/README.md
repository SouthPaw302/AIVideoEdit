# Sigh No More — Shot Packages

18 finished production shot packages were built for this film. Each package is represented under `shot_packages/<shot-id>/` and its timing/story role is defined in `SHOT_LIST.md`.

Large binary assets (source PNGs, synthetic depth masks, internal-motion masks, proof MP4s and finished shot MP4s) remain outside git; git preserves package identity, recovery metadata, FX lock, QC and final-output hashes.
