# Visual DNA — Tribal House Remastered

## Locked picture language
Nocturnal ceremonial world. Volcanic/desert textures. Sacred ruins, circles, thresholds and corridors. Fire, embers, ash, smoke, dust and reflected light. One coherent mythic central spirit whose phases read as the same force.

## Story spine
Invocation -> Gathering -> First Manifestation -> Procession / Passage -> Possession / Peak Build -> Threshold Crossing -> Apotheosis -> Release -> Afterglow / Exit.

## Motion law
Internal material motion first. Fire behaves like fire, smoke like smoke, ash/dust locally, reflections independently. Camera movement is secondary and bounded. Protect hero identity, silhouette, anatomy, architecture and horizon topology.

## Negative rules
No lyric literalism. No generic EDM geometry reel. No random unrelated montage. No whole-frame wobble/shake as animation. No accidental horror framing. No drift between unrelated heroes.
