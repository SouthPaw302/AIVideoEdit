# After Midnight analysis evidence

The audio subdirectories contain one canonical `AUDIO_MAP.json`, `EDIT_MAP.json`, and `REACTIVE_CONTROLS.json` set per Drive WAV master. The visual subdirectories contain candidate-only `HERO_LIBRARY.json` manifests produced from the three authorized Drive reference videos.

The source videos and WAV masters remain in Drive. The manifests preserve Drive IDs, source SHA-256 identities, measured timings, candidate counts, and selection evidence. Candidate frame PNGs are local review derivatives and are not production canon.

Production is intentionally still `SOURCE_INGESTED`: lyric authority and semantic still selection must be resolved before `REFERENCES_ANALYZED`, storyboard lock, or proof rendering.
