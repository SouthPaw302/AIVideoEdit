# Production Branch Template
Use only on `song/<slug>`. A newly supplied audio master creates a fresh branch from `main` unless the user explicitly identifies an existing branch to continue.

Minimum branch-local package: `PROJECT.md`, `STATUS.md`, `HANDOFF.md`, `LYRICS.md` when applicable, `VISUAL_DNA.md`, storyboard/`SHOT_LIST.md`, FX plan/manifest, `ASSET_MANIFEST.json`, `RENDER_HISTORY.md`, `QC.md`, `shot_packages/`.

Before inventing technology, inspect the project-neutral main system. Reusable discoveries return to `main` only after generic extraction, project-neutral naming/path cleanup, proof/QC, and canonical registration.
