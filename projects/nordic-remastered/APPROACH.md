# Visual / Media Approach — LOCKED

## Direction
Reference-led hybrid.

The supplied video is the visual authority for hero identity, wardrobe, world, craft language, palette, lighting, framing, and motion restraint. The phone/social-feed wrapper is analysis noise, not part of the artistic master.

## Coverage method
The source clip is too repetitive for 137.92 seconds, so production expands the same world through **five Batch-10 stacks (50 primary scene plates)**. Each accepted plate becomes recoverable canon and may feed multiple bounded animation/FX variants.

## Hybrid behavior
- **Living-scene**: paired portraits, close-ups, holds, wind/hair/cloth/dust/light behavior, restrained depth/parallax.
- **Cinematic**: wider environment/craft coverage, alternate angles, walking/turning action states, detail inserts, high-energy progression.
- Every shot remains inside the same visual world.

## Music mapping
Use MainV2's canonical audio-map grid (184.57 BPM) with half-time visual weight (~92.29 BPM). Phrase/energy anchors control edit pace; do not cut mechanically on every beat.

## Batch cadence
B01 hero/world foundation → proof/FX gate → B02 world expansion → proof/FX gate → B03 progression → gate → B04 drop/re-entry → gate → B05 climax/resolution → gate → assembly.

## Non-negotiables
Faces, anatomy, hero identity, suit geometry, craft topology, horizon, scale, lens logic, and golden-hour light direction are protected. Internal scene motion precedes camera motion. No endless zoom, shake, generic wobble, or silent regeneration of accepted media.
